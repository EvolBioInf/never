README for neighbors.evolbio.mpg.de/databases

This directory contains versions of the Neighbors database used by many of the programs in the Neighbors package. The Neighbors database is an Sqlite database, which we supply as binary files with extension db, except for the latest version, neidb. In addition, we supply the raw data from which the database was computed as compressed tar files with extension tgz. Once unpacked, the raw data files serve as input for the Neighbors program makeNeiDb to compute the database files. The raw data itself is taken from the NCBI taxonomy and from lists of genome assemblies in Genbank and Refseq.
